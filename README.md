# 🏥 TRIAGE-X

> **AI-Powered Medical Triage System** — Built in 24 hours at [Hackathon Name]

## 📋 Overview

TRIAGE-X is a next-generation clinical command center designed to replace the traditional "First-In, First-Out" queue model with an AI-driven medical priority system. Our prototype intelligently assesses patient symptoms, vital signs, and urgency levels to optimize emergency room workflows and reduce wait times for critical cases.

## 🎯 Problem Statement

Traditional hospital triage systems often rely on manual assessment and FIFO queuing, leading to:
- Delayed care for critical patients
- Overwhelmed emergency departments
- Inefficient resource allocation
- Increased patient wait times

## ✨ Solution

TRIAGE-X addresses these challenges through:
- **AI-Powered Assessment**: Automated symptom analysis and risk stratification
- **Dynamic Priority Queue**: Real-time triage categorization (Red/Yellow/Green)
- **Smart Routing**: Directs patients to appropriate specialties and examinations
- **Instant Anamnesis**: Generates structured patient summaries for medical staff

## 🏃 Quick Start

### Prerequisites
- Node.js v16+ / Python 3.8+
- npm / pip
- [Your database]

### Installation

1. **Clone the repository**
```bash
git clone [https://github.com/](https://github.com/)[your-username]/triage-x.git
cd triage-x
```

2. **Install dependencies**
```bash
# Frontend
cd frontend
npm install

# Backend
cd backend
pip install -r requirements.txt
# or
npm install
```

3. **Set up environment variables**
```bash
cp .env.example .env
# Edit .env with your configuration
```

4. **Run the application**
```bash
# Start backend server
python app.py
# or
node server.js

# Start frontend (in another terminal)
npm start
```

5. **Access the application**
Open your browser and navigate to `http://localhost:3000`

## 🧪 Usage

1. **Patient Registration**: Enter patient details and symptoms
2. **AI Assessment**: System analyzes symptoms and assigns priority
3. **Triage Category**: Patient receives Red/Yellow/Green classification
4. **Queue Management**: View real-time emergency department queue
5. **Doctor Dashboard**: Medical staff access prioritized patient list
